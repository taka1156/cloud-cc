AWS アイコンの置き場所
======================

ゲームの盤面と山札には、ここにあるファイルをサービスごとに読み込みます。
ファイル名は services.json の id に合わせてください。

  assets/aws/ec2.svg
  assets/aws/s3.svg
  assets/aws/route53.svg
  ...

ファイルが無いサービスは、サービス色の四角いバッジで代わりに表示されます。

公式のアイコン（AWS Architecture Icons）は AWS のサイトから入手できます。
ダウンロードしたSVGを上記の名前に変えて置いてください。
利用の条件は AWS のアイコン利用規約を確認してください。
