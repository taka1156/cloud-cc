# cloud-cc 問題作成スキル

ゲームは「決まった構成図（テンプレート）の枠に、山札のカードを置く」形式。問題セットは、どのテンプレートを使い、どの枠に何を置けば正解かを持つ。

- サービスカード: `data/services.json`（固定マスター。置ける枠の種類 `placeableIn` と、一緒に使えない相手 `cannotWith` をカード側に持つ）
- 構成図テンプレート: `data/templates/<id>.json`（枠の位置と種類 `kind`、Region/AZ などのゾーン）
- 問題セット: `data/problems/<id>.json`（1問題1ファイル。分類ごとに配列でまとめてもよい）

## 手順

1. `data/services.json` と `data/templates/` を読み、使えるサービスIDと、テンプレートごとの枠ID・枠の種類を確認する。
2. 問題に合うテンプレートを選ぶ。合うものが無ければ、新しいテンプレートを作るか、ユーザーに確認する。サービスは勝手に追加しない。
3. 既存の `data/problems/` と `id` や題材が重複しないことを確かめる。
4. 次の形式で問題を書く。
5. `node scripts/build.mjs` で検証する。エラーが出たら直して再実行する。
6. 完了報告では、ファイルパス、使ったテンプレート、正解の枠と山札の枚数、検証結果を短く伝える。

## 形式

```json
{
  "schemaVersion": 2,
  "id": "web-3tier-002",
  "title": "3層構造のWebアプリ",
  "difficulty": 2,
  "tags": ["ソリューションアーキテクト", "3層"],
  "statement": "問題文（プレイヤーに見せる状況説明）",
  "requirements": ["要件1", "要件2"],
  "template": "three-tier",
  "deck": ["route53", "alb", "ec2", "ec2", "rds", "s3"],
  "answer": {
    "slots": { "dns": "route53", "lb": "alb", "app1": "ec2", "app2": "ec2", "db1": "rds" }
  },
  "links": [["dns", "lb"], ["lb", "app1"], ["lb", "app2"], ["app1", "db1"]],
  "explanation": "解説"
}
```

## 作問のルール

- `answer.slots` は「枠ID → サービスID」。枠IDはテンプレートの `slots[].id`。盤面にはここに書いた枠だけが表示されるので、問題に関係する枠だけを書く。
- 正解のサービスは、その枠の `kind` が `services.json` の `placeableIn` に含まれていること。
- 同じサービスを2つの枠で使うとき（例: 2つのAZの EC2）は、`deck` にもその枚数を入れる。
- `cannotWith` で一緒に使えないとされたサービスを、同じ正解に入れない。
- `links` は構成図に最初から描く線。`answer.slots` に書いた枠IDの組で、向きはない（`["a","b"]` と `["b","a"]` は同じ。重複はエラー）。
- 線が、つないでいない別の枠の上を通らないように枠を選ぶ（通ると、その枠を経由してつながっているように見える）。
- `deck` は正解のカードに、紛らわしいカードを 1〜3 枚混ぜる。良いダミーは次の2種類。
  - 同じ枠に置けるが要件に合わないもの（例: リレーショナルDBの要件に DynamoDB）
  - 盤面に置ける枠がないもの（例: 3層構成に SQS）。「使えないカード」を見分ける練習になる
- `difficulty` は 1（正解の枠2〜3個）、2（4〜5個）、3（冗長化や組み合わせの判断を含む応用）が目安。
- `requirements` は、正解を一意に絞れるように具体的に書く。ダミーが「同じ枠に置けるが不正解」になる理由が、要件から読み取れるようにする。
- `explanation` には「なぜこの配置か」と「ダミーが不正解な理由」を書く。
- 文章は日本語で書く。

## 検証でよくあるエラー

- `template が見つかりません`: `data/templates/` にない id を指定している。
- `テンプレートにない枠`: `answer.slots` や `links` の枠IDが間違っている。
- `は枠 "x"（kind）には置けません`: そのカードの `placeableIn` に枠の種類が無い。
- `山札には n 枚しかありません`: 同じカードを複数の枠に置くのに、`deck` の枚数が足りない。
- `一緒には使えません`: `cannotWith` の組み合わせを正解に入れている。
